# Paradise-Nursery

Welcome to Paradise Nursery, an online plant shopping web application designed to bring nature closer to your home. 

## Project Overview
This project is an interactive e-commerce web application built using React and Redux. It allows plant enthusiasts and users to explore a wide variety of houseplants categorized by type, view detailed information including images, names, and prices, and manage their shopping cart dynamically.

## Key Features
* **Landing Page:** An attractive entry point featuring the company name and a "Get Started" button that leads to the product catalog.
* **Product Listing:** Browse unique houseplants organized into distinct categories with thumbnail images and pricing.
* **Interactive Shopping Cart:** Easily add items to the cart, adjust quantities, calculate total costs instantly, and remove items as needed.
* **Navigation Bar:** Seamlessly switch between the home page, product listing, and cart view with a dynamic item counter.
